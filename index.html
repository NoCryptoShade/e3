Debrief

  1. How many shells did you get, and which user did each land you as?
  2. Sort your routes into groups by why the service let you in. Not by port, not by tool. You should end up with four or five groups. If two reasons read the same, you have written the symptom instead of the cause.
  3. Which routes had a CVE and which did not? If you had only a CVE-based scanner report for this host, how many of your shells would you have seen coming?
  4. Rank your routes by how hard the finding would be to fix, not by how bad it is. The order is not what you expect.
